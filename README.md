# Mandinga's Rotational Reminders

## English

A collection of class- and specialization-specific rotation reminders for World of Warcraft: Midnight 12.1.5.

### Available reminders

#### Subtlety Rogue

When Shadow Dance ends while Shadow Blades is still active, the addon says the localized spell name once using WoW’s text-to-speech.

- Reads both buffs directly from the player whenever the game exposes them to addons. This works with the Cooldown Manager disabled.
- When the game restricts direct aura lookups, the reminder uses visible Tracked Buffs or Tracked Bars entries in the Cooldown Manager. It stays quiet if either buff’s state is still unavailable.
- Plays the raid-warning sound through the same sound-effects channel as Cooldown Manager alerts if the localized name is unavailable or the standalone text-to-speech path has no voice.

## Português

Uma coleção de lembretes de rotação por classe e especialização para World of Warcraft: Midnight 12.1.5.

### Lembretes disponíveis

#### Ladino de Subterfúgio

Quando Dança das Sombras termina e o efeito de Lâminas Sombrias permanece ativo, o addon usa a síntese de voz do WoW para dizer uma vez o nome localizado da habilidade.

- Consulta os dois efeitos diretamente no personagem quando o jogo disponibiliza esses dados aos addons. Isso funciona com o Gerenciador de Recarga desativado.
- Quando o jogo restringe a consulta direta, o lembrete usa as entradas visíveis de ícones ou barras de bônus do Gerenciador de Recarga. O aviso fica em silêncio se o estado de algum dos efeitos continuar indisponível.
- Se o nome localizado estiver indisponível ou a síntese de voz independente não tiver uma voz disponível, toca o som de aviso de raide no mesmo canal de efeitos sonoros dos alertas do Gerenciador de Recarga.
