# Mandinga's Rotational Reminders

## English

A collection of class- and specialization-specific rotation reminders for World of Warcraft: Midnight 12.1.5.

### Available reminders

#### Subtlety Rogue

When Shadow Dance ends while Shadow Blades is still active, the addon uses Blizzard’s Cooldown Manager text-to-speech to say the localized spell name once.

- Plays the raid-warning sound through the same sound-effects channel as Cooldown Manager alerts if the localized spell name is unavailable.
- Reads both buffs from visible Tracked Buffs or Tracked Bars groups in the Cooldown Manager. The two buffs can be in different groups.
- Pauses alerts while the relevant tracker is hidden, during Edit Mode, or when the client restricts access to either buff’s state. Rechecks both buffs after a Cooldown Manager layout change.

## Português

Uma coleção de lembretes de rotação por classe e especialização para World of Warcraft: Midnight 12.1.5.

### Lembretes disponíveis

#### Ladino de Subterfúgio

Quando Dança das Sombras termina e o efeito de Lâminas Sombrias permanece ativo, o addon usa a síntese de voz do Gerenciador de Recarga da Blizzard para dizer uma vez o nome localizado da habilidade.

- Se o nome localizado da habilidade estiver indisponível, toca o som de aviso de raide no mesmo canal de efeitos sonoros dos alertas do Gerenciador de Recarga.
- Consulta os dois efeitos nos grupos visíveis de ícones ou barras de bônus do Gerenciador de Recarga. Os efeitos podem ficar em grupos diferentes.
- Pausa os avisos enquanto o grupo correspondente está oculto, durante o Modo de Edição ou quando o cliente restringe o acesso ao estado de um dos efeitos. Verifica os dois efeitos novamente após mudanças no layout do Gerenciador de Recarga.
